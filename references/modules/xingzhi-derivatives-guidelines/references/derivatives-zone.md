# 衍生品专区与收益互换

来源：MasterGo 画板 `衍生品专区`（`84:92723`）与 `收益互换`（`84:94720`）。

## 页面定位

- 将专区作为业务介绍与关键入口页，不做成纯资讯流。
- 页面按“导航 → 交易服务 → 主推业务 → 产品/解决方案 → 专家服务 → 投教课堂”组织。
- 以 `375px` 移动画布为基准，常规左右边距 `16px`，主内容宽 `343px`。

## 顶部与交易服务

- 导航标题为“衍生品业务专区”，使用 `18/26 500`；保留返回和必要的右侧操作。
- “交易服务”使用模块标题 `16/24 500`。
- 场外期权、收益互换等关键入口使用双列操作卡，优先采用行知标准 `168px + 8px` 栅格。
- 每个操作卡只放一个明确动作，如“去询价”“去交易”；标题、说明与动作不可争夺层级。

## 主推业务与解决方案

- 顶部业务 Banner 使用 `343 × 112px`、`8px` 圆角，并遵循运营图安全区。
- 示例“国际化衍生品服务”是单一重点入口；使用“点击了解”等短动词，不叠加多个同级 CTA。
- 大宗商品、跨境收益互换、收益凭证等同级分类保持统一尺寸和命名结构。
- 选中分类后展示对应解决方案，不在同一视图混入其他分类的详情。
- 大宗商品互换的示例内容包括境内外场内品种与境外掉期合约；长列表先展示代表项，再用“查看更多”展开。
- 产品介绍不得暗示保本、确定收益或无风险；适用范围和排除项按已审批文案呈现。

## 收益互换子页

- 顶部导航标题为“收益互换”。
- 首屏使用两张大入口卡：跨境收益互换、大宗商品互换。
- 卡片包含业务名称和一句价值说明；整卡可点击，点击范围与视觉区域一致。
- 入口卡的视觉可采用浅青/浅蓝渐变和 `8px` 圆角，但不把运营色当作状态色。
- 子页只负责选择业务方向；具体交易或咨询流程在下一页承载。

## 专家服务与投教

- 专家服务包含头像、姓名、专业简介和“专家咨询”；咨询入口必须与具体专家或团队归属一致。
- 同屏专家头像与文字样式保持一致，横向溢出时可滚动，不挤压姓名。
- 投教课堂使用标准信息流，标题、类型、日期和缩略图分层；“更多”进入完整列表。
- 投教内容与交易入口必须视觉分区，不能让文章卡看起来像下单按钮。

## 状态与返回

- 入口不可用、未登录、无权限和建设中必须分别反馈。
- 从详情或咨询返回时保留当前分类、展开状态和滚动位置。
- 页面恢复时不自动切换用户已选择的产品方向。

## 验收

- 检查 `375/343/16px` 栅格、导航和模块标题。
- 检查关键交易入口是否早于长篇业务介绍。
- 检查 Banner、双列卡、专家与信息流是否调用对应行知组件。
- 检查每个入口动词、跳转目标、登录/权限反馈和返回状态。
