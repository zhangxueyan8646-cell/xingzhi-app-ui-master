## 交易页收藏入口

- 在交易申请页的挂钩标的代码旁显示自选图标；未收藏和已收藏状态必须与服务端数据同步。
- 点击未收藏图标时，根据可用分组数量决定直接加入或打开“添加到”抽屉；不要在成功响应前切换为最终收藏态。
- 点击已收藏图标执行移除当前自选关系；操作成功后使用轻量 Toast“移除自选成功”。
- 添加成功使用轻量 Toast“添加自选成功”，不遮罩页面、不清空交易表单，也不改变当前账户和标的。
- 请求失败时恢复操作前图标状态，并说明失败原因；连续点击需防重复提交。

## 添加到与移动到

- 存在多个可用分组时使用底部 Popup，标题为“添加到”或“移动到”，根据当前动作准确区分。
- 画板抽屉宽 `375px`、示例高 `314px`，顶部圆角 `16px`，标题栏 `44px`，右侧关闭图标，黑色 `40%` 遮罩。
- 分组行高 `40px`，左右内边距 `16px`；使用 `20 × 20px` Checkbox，控件与分组名间距 `16px`。
- 允许标的同时属于多个分组，因此采用多选语义；打开抽屉时显示当前所属分组，取消/关闭不得提交暂存修改。
- 底部主按钮为 `343 × 44px`“确认”，操作区避让 `34px` Home Indicator。
- “添加到”在现有所属集合上增加/移除勾选关系；“移动到”按产品规则变更当前分组归属。若移动仍允许多组，必须明确是复制还是移除原组，不能由 UI 猜测。
- 提交前重新校验目标分组是否存在；分组被删除或权限变化时保留标的上下文并刷新列表。

## 我的自选

- 页面标题为“我的自选”，保留返回、分组 Tabs、标的搜索、行情卡列表和业务底部 Tab Bar。
- 分组 Tabs 包含系统“默认”和用户分组，例如港股、美股；使用一级 Tabs：选中 `16/24 500`，未选中 `14/22 400`。
- 分组过多时横向滚动并固定更多入口；切换分组后保留每组的滚动位置，不改变其它分组排序。
- 标的卡展示证券名称、代码、市场、最新价、涨跌幅、最高、最低、昨收、开盘、收盘、总量、涨停、跌停和总金额。
- 价格与涨跌使用市场约定色，同时保留正负号和文字标签；行情未返回时显示占位，不以 `0` 冒充。
- 卡片操作使用紧凑胶囊按钮：当前分组内标的显示“移动到”和“去下单”；搜索结果或未分组标的使用“添加到”和“去下单”。
- “去下单”进入交易申请并带入标的，不自动提交订单；返回后恢复自选分组与滚动位置。

## 标的搜索

- 使用 `343 × 36px` 搜索框，背景 `#F5F7FA`、全圆角，支持输入、清除和明确的“搜索”动作。
- 按证券代码或名称匹配，候选结果显示完整代码与市场后缀；高亮匹配文字但不改变原始代码。
- 搜索态与分组列表态分开；清除关键词后恢复进入搜索前的分组和列表位置。
- 搜索结果逐条显示是否已加入自选；添加/取消操作只更新对应标的，不刷新或重置整个关键词列表。
- 搜索结果行的右侧收藏控件用于快速切换：未加入时显示添加态，已加入时显示移除态；图标、文案、可访问状态和真实归属必须一致。
- 快速添加只有在目标分组唯一或产品已定义默认分组时直接提交；存在多个候选分组时打开“添加到”抽屉。
- 从搜索结果快速移除时，若标的属于多个分组，必须先明确移除范围；不能用一次点击静默清除全部归属。
- 空关键词、无结果、加载中和加载失败分别反馈，不用空白列表代替。

## 移除自选

- 从某一分组移除时使用确认 Modal，文案包含目标分组，例如“确认将该条标的从港股中移除吗？”。
- 弹窗宽 `270px`、圆角 `16px`、黑色 `40%` 遮罩；左侧取消、右侧确认，主要操作唯一。
- 确认只移除文案中指明的分组关系；标的仍属于其他分组时不得从全部自选中删除。
- 操作成功后更新当前列表；若当前组因此为空，切换为对应空态。失败时保留标的和弹窗上下文。

## 新建与管理分组

- 更多入口使用锚定 Popover，示例宽 `112px`、两项总高 `84px`；菜单项为“新建分组”“管理分组”，图标 `20px`、行高约 `40px`。
- Popover 使用白底、`8px` 圆角和轻阴影；点击外部关闭，不添加全屏遮罩。
- 新建分组使用输入型 Modal，宽 `270px`；标题“新建分组”，输入区 `238 × 36px`、`#F5F7FA`、`8px` 圆角。
- 分组名最多 `12` 个字；空值时确认按钮保持未满足条件态，输入有效后激活。
- 重名时在输入区下显示“分组名称重复，请重新输入”，保留用户输入并将确认置为不可提交。
- 管理分组页按“名称 / 编辑 / 排序 / 删除”展示用户分组；系统“默认”组不出现在可编辑列表中。
- 编辑打开“重命名”Modal，沿用 `12` 字限制和重名校验；成功后同步 Tabs 与标的所属信息。
- 排序使用清晰拖动把手，拖动完成后保存并同步我的自选 Tabs；失败时恢复原顺序。
- 本批画板没有给出删除确认和非空分组迁移规则。实现删除前必须以 PRD 明确：标的是移入默认组、保留其他归属还是一并移除，禁止自行推断。

## 空态与反馈

- 无任何用户分组时显示页面级空态：“暂无分组，请新建分组后添加自选标的”，并提供 `104 × 36px`“新建分组”按钮。
- 当前分组存在但没有标的时应使用“暂无自选标的”，不要误写为“暂无分组”。
- 添加/移除成功使用自动消失 Toast；新建、重命名、移动失败使用可定位的内联错误或 Modal，不用成功 Toast 覆盖失败。
- 所有操作更新分组计数、Tabs、卡片按钮和交易页自选图标，避免局部状态不一致。

## 验收清单

- [ ] 交易页自选图标、Toast 与服务端收藏状态同步。
- [ ] 添加到/移动到抽屉的当前勾选、暂存、确认和取消行为准确。
- [ ] 分组 Tabs、行情卡、搜索和去下单返回路径保持状态。
- [ ] 移除确认明确目标分组，不误删其它分组关系。
- [ ] 新建/重命名的 `12` 字限制、空值、重名和按钮状态完整。
- [ ] 管理分组的编辑、排序、删除权限和默认组边界清楚。
- [ ] 空分组与空标的语义分开，固定操作与底部 Tab Bar 不遮挡内容。
