## 投资理财首页

- 使用 `375px` 移动画布；状态栏下接 `44px` 导航，主内容按 `16px` 页面边距与 `343px` 内容宽组织。
- 保持“账户/登录与资产摘要 → 业务金刚区 → 重点活动或服务入口 → 私募管理人/公募基金等业务内容 → 指数或产品信息 → 相关资讯 → 免责声明”的决策顺序。
- 私募创造营是运营活动入口，不替代“私募管理人”长期业务入口。活动状态使用“去报名、查看、回放”等明确动作。
- 登录前展示登录入口与必要说明；登录后才展示账户相关资产数据。禁止用演示账户、资产或日期充当真实数据。
- 金刚区名称、角标和排序由产品配置控制；“私募管理人、收益凭证、公募基金、私募基金、特色研投、我的自选”等不因画板出现就强制全部展示。
- 产品净值、涨跌、指数温度与观点必须显示数据日期或更新时间；数值颜色只表达既定业务语义，不构成涨跌预测。
- 相关资讯与业务操作分区；资讯行保持标题、来源、日期层级，不将资讯卡伪装成申购或申请按钮。
- 页面末尾保留完整合规免责声明，不截断、不自行改写。

## 创造营活动页

- 顶部使用全宽活动主视觉；主视觉之后放一级 Tabs：“活动简介 / 活动规则 / 我的报名”。
- 一级 Tab 选中态使用 `16/24 500` 与青色短指示条，未选中态使用 `14/22 400`；切换时保留活动上下文。
- 活动简介按“活动介绍 → 活动权益”组织。长介绍默认可折叠，入口文案使用“展开/收起”；展开后内容自然增高，不覆盖底部操作。
- 活动权益卡分别呈现品牌宣传、研究宣传、交易系统等支持；权益标题与正文保持明确层级，不把权益描述写成已承诺结果。
- 活动规则使用短条目逐条展示；规则文本必须来自活动运营或合规批准版本。
- 策略分组使用独立卡片行，展示策略名与“查看评分指标”入口；策略名称、数量和排序由活动配置驱动。
- 评分指标使用居中 Modal：`270px` 宽、`16px` 圆角、黑色 `40%` 遮罩。指标名与权重逐行对齐，权重总和由数据校验；底部仅保留明确关闭操作。
- 页面底部固定主操作用于“立即报名”；已报名、不可报名、活动未开始、活动结束等状态必须替换动作与说明，不只改变颜色。

## 内容与状态

- 活动名称、季次、城市、时间、规则、策略和评分权重全部绑定活动配置。
- “我的报名”显示当前账户对应的报名记录；无记录使用报名空态，有进行中流程则恢复草稿。
- 点击报名入口前校验登录、机构身份、活动状态与报名资格；阻断时说明原因并提供可执行路径。
- 活动主视觉允许活动专属风格，但正文、Tabs、卡片、弹窗和按钮继续使用行知组件规范。

## 检查

- 检查首页入口与活动页的返回关系、登录态和滚动位置恢复。
- 检查主视觉不会压住状态栏、Tabs 或关键文字。
- 检查折叠内容、评分弹窗和底部报名操作不会相互遮挡。
- 检查金融数值、活动规则、免责声明和对外宣传文案均有权威来源。
