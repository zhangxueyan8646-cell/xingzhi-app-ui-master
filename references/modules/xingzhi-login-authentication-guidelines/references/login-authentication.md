## 入口与访问决策

1. 记录来源内容、内容 ID、分享渠道、当前滚动位置和用户触发动作。
2. 判断运行环境：App 内使用完整内容页；站外先展示可公开的预览层。
3. 判断动作：浏览摘要可继续；阅读全文、观看回放或参与活动属于受限动作。
4. 判断登录：未登录进入手机号认证；已登录继续判断服务权限。
5. 判断权限：境内/境外研究服务权限不匹配时显示说明弹窗或跳转到正确站点，不重复要求登录。
6. 完成认证后返回原内容，不跳到无关首页；恢复原动作或提供明确的继续按钮。

登录状态、研究服务签约状态、内容权限和 App 安装状态是四个独立条件，不可互相替代。

## 站外内容预览

### 直播/回放

- 保留封面、播放标识、活动标题、标签、时间、主讲人、相关介绍和免责声明。
- 未进入 App 时，播放受限回放的核心动作使用“打开App，观看回放”。
- 按钮固定在底部操作区时必须避让 Home Indicator；不能遮挡免责声明正文。
- App 内对应页使用“立即参与”等业务动作，不继续展示站外打开 App 文案。

### 研报

- 站外保留标题、日期、作者、标签和有限摘要，明确显示“更多精彩尽在行知APP”。
- “点击阅读全文”是内容内的认证触发入口；底部“去行知APP发现更多内容”是 App 引流入口，两者语义不得互换。
- 截断处不可伪装为全文结束；用明确提示、渐隐或内容边界表示后续内容受限。
- App 内完整版可以展示作者、相关推荐、免责声明、评论及互动栏。

## 手机号登录注册

### 页面结构

- 参考画布为 `375 × 812px`；顶部含系统状态栏和 `44px` 的 Web 容器栏。
- 主视觉用于说明“登录后查看精彩内容”，不得覆盖输入与提交区域。
- 手机号区为无标题、带区号下拉的输入：画板宽 `311px`、左边距 `32px`，区号与箭头区域约 `42px`。
- 默认显示 `+86` 和“请输入手机号”；更换区号时同步号码长度、格式和校验规则。
- 输入下方说明“未注册的手机号验证后自动注册账号”。产品实际采用自动注册时必须在提交前清楚告知。
- 主按钮画板为 `311 × 44px`、胶囊圆角，文案“登录/注册”；按钮是否启用必须与手机号有效性一致。
- 账号密码登录、邮箱验证码登录属于备用路径。仅在业务真实支持时展示，并保留来源内容回跳参数。

### 输入与校验

- 仅允许符合所选区号规则的号码进入下一步；空值、格式错误和网络失败分别反馈。
- 格式错误应在当前字段就地修正；网络异常可使用 Toast，但不能清空用户已输入号码。
- 点击提交后锁定重复点击，显示局部加载；验证码发送成功后再切换到验证码页。
- 不要把“登录/注册”文案改成已完成状态，也不要在服务端确认前声称已登录。

## 六位验证码

- 顶部显示接收号码。默认进行脱敏，仅保留区号及必要的前后数字；提供清晰的返回/修改号码入口。
- 使用 `Input` 专用验证码结构：6 个字符位，整体约 `308 × 38px`，左右内边距 `12px`。
- 每个字符 `24/26px`，下划线宽 `34px`；当前输入位为 `#00D2F0`，其余位使用 `#E6EBF0`。
- 当前选稿间距为 `16px`，基础 Input 规范记录为 `20px`；新页面以 `input.md` 的专用组件 token 为准，复用现有组件时保持组件实例结构。
- 支持系统短信验证码自动填充、顺序输入、退格删除和粘贴完整验证码。
- 重发按钮在倒计时期间显示“重新获取（56s）”等剩余时间并禁用；倒计时结束后切换为可点击“重新获取”。
- 重发不会清除当前号码；收到新验证码后旧验证码失效，并重新开始倒计时。
- 六位填写完成不等于验证成功。点击“登录”或产品明确采用自动提交时才发起校验，并防止重复请求。
- 验证码错误、过期、次数过多、网络异常必须区分；错误后保留号码，清理或聚焦验证码位，使用户可继续修正。

## 权限不匹配弹窗

- 当用户已经登录，但当前研究服务签约地域与内容站点不匹配时使用权限提示，不重新进入验证码流程。
- 选稿文案说明：内容仅对境内研究服务签约用户可见；识别到境外研究服务时，可前往行知境外版。
- 使用行知 Modal：宽 `270px`、圆角 `16px`、黑色 `40%` 全屏遮罩。
- 标题“温馨提示”使用 `16/24px` Medium `500`；正文使用 `14/22px` Regular `400`。超过两行左对齐。
- 单个操作可使用“知道了”关闭；若产品提供“前往境外版”，将其作为唯一主要动作或与取消组成主次明确的双操作。
- 关闭弹窗后回到原研报预览位置；背景交互在弹窗开启期间必须锁定。

## 流程状态与回跳

推荐状态机：

`公开预览 → 触发受限动作 → 未登录 → 输入手机号 → 验证码 → 验证成功 → 权限判断 → 原内容/目标动作`

可能分支：

- 已登录且有权限：直接继续原动作。
- 已登录但权限不匹配：显示权限提示或正确站点入口。
- 取消登录：回到原预览和原滚动位置，不进入空白页。
- 会话过期：保留来源参数，重新认证后恢复上下文。
- 登录失败：停留在可修正步骤；不要返回流程起点或清空有效输入。
- App 未安装：提供受控下载/应用商店路径，并保留内容深链。

## 隐私安全与异常

- 手机号在输入页可由用户主动查看；进入验证码页后默认脱敏。不要在日志、埋点或错误文案中记录完整手机号或验证码。
- 验证码输入不可回显为明文日志，不缓存到非安全持久层；离开流程或验证成功后及时清理。
- 对发送验证码、验证验证码和登录操作设置频率限制、次数限制和防重放机制。
- 区分“未登录”“登录失效”“无内容权限”“研究服务地域不匹配”“App 未安装”，并给出各自恢复动作。
- 自动注册必须与隐私政策、用户协议和业务合规要求一致；若需要用户主动同意，使用明确且不预选的同意控件，不以继续使用代替同意。
- 未选画板没有展示协议勾选组件；不要仅凭本 Skill 自行补画，PRD 或合规规则要求时再调用 Checkbox/Modal 对应规范。

## 视觉与组件约束

- 中文文本统一 `PingFang SC`。标题 Medium `500`，正文 Regular `400`，在每个实际文字节点显式设置 family 和 weight。
- 标题使用 `20/28、18/26、16/24、14/22`；正文使用 `16/24、14/22、12/18、10/14`。验证码字符 `24/26` 为组件例外。
- 画板主视觉“登录后查看精彩内容”使用了 `Alimama ShuHeiTi 24px`，属于旧稿展示值；新页面改用最接近语义的行知标题 token。
- 主操作使用 `#00D2F0`、白字、`44px` 高和胶囊圆角；未满足提交条件时使用规范中的未满足条件态，不用可点击的饱和主色伪装。
- 页面通用左右边距优先 `16px`。登录选稿中的 `32px` 是独立站外登录表单宽度；复刻该模式可保留，普通行知表单仍遵循 `16px` 页面边距。
- Modal 使用 `270px` 宽、`16px` 圆角和黑色 `40%` 遮罩。底部固定动作避让 `34px` 安全区。
- 内容卡片、标签、免责声明、信息流与分享栏由相应行知组件或业务 Skill 约束，不在本 Skill 复制一套新 token。

## 验收清单

- [ ] 入口环境、内容类型、登录状态、权限状态分别判断。
- [ ] 站外直播/研报保留合理预览，受限动作入口文案准确。
- [ ] 手机号格式、区号、自动注册说明和备用登录方式与产品能力一致。
- [ ] 六位验证码、当前位、倒计时、重发、错误、过期和提交态完整。
- [ ] 登录成功后回到原内容与原触发动作，取消/失败也有稳定返回路径。
- [ ] 权限不匹配使用提示弹窗，不误导为登录失败。
- [ ] 手机号脱敏、验证码清理、频率限制和防重复提交落实。
- [ ] PingFang SC、500/400 字重、字号行高和组件例外在最终文字节点中真实存在。
- [ ] 站外引流、App 内动作、阅读全文和观看回放没有混用。
- [ ] 状态栏、Web 容器栏、底部操作区和 Home Indicator 不互相遮挡。
