# 行知首页规范

## 使用方式

1. 先调用 `xingzhi-design-guidelines`，并按实际页面读取其基础规范和相关组件规范。
2. 完整读取 [references/home-page.md](references/home-page.md)。
3. 将首页画板识别为同一页面的首屏、滚动态或长页状态，不把状态稿复制成独立页面。
4. 优先复用当前 MasterGo 文件中的行知组件、样式和图标资产；业务文案与内容数据按 PRD 动态填充。
5. 创建或修改后检查真实文字图层：中文界面为 `PingFang SC`，标题显式 `500`，正文显式 `400`。

## 规范优先级

冲突时按以下顺序处理：

1. 当前 PRD 的业务内容、权限和流程要求。
2. 本 Skill 的首页组合、入口与滚动规则。
3. 行知具体组件规范。
4. 行知基础颜色、文字、间距、圆角和阴影规范。
5. 所选历史画板中的局部样式。

历史画板只证明页面结构与状态关系。不得用旧画板的异常字号、特殊字体、裁切错误或重复隐藏图层覆盖当前行知规范。

## 首页模型

- 基准画布为 `375px`，标准内容区左右各 `16px`，内容宽 `343px`。
- 默认采用内容发现型结构：状态栏 → 固定搜索头部 → 金刚区 → Banner → 一级内容 Tabs → 双列业务卡 → 热点直击 → 信息流。
- 底部快讯与 `82px` Tab Bar 组成固定底部区域；正文必须预留其完整高度。
- 只有一个首页根页面。首屏、上滑和长截图是同一页面的状态，不是三张需分别维护的页面。
- 首页业务入口、分类名称、Banner、热点和信息流均由配置或服务端数据驱动，不把样例文案写成规范常量。

## 强制约束

- 中文普通界面文字使用苹方；“热点直击”“金牌大咖”等特殊字形仅在已有审核通过的图片/品牌字资产中保留，否则改用 `PingFang SC Medium 500`。
- 顶部只保留一个可见搜索入口。源文件中的全宽与紧凑搜索重叠层是组件状态，不得同时生成。
- 一级 Tabs 同时仅有一个选中项；溢出时使用行知 Tabs 的横滑或更多规则，不擅自加入自动滚动和暂停按钮。
- Banner 使用 `343 × 112px`、`8px` 圆角；轮播页数和定位器数量一致，单张 Banner 不显示无意义定位器。
- 双列卡片按 `168px + 8px + 168px` 等分处理；源稿中的 `167px` 只是像素取整，不建立新尺寸。
- 热点模块高度随标题、标签和信息行增长，保留底部内边距；禁止固定 `125px` 后裁掉最后一行。
- 固定区域不得遮住正文、信息流加载反馈、触控区域或系统安全区。
- 加载、空态、错误、无权限和无结果必须使用各自语义状态，不能都显示为“暂无数据”。

## 验收

- 检查页面结构、固定区域与滚动态是否与 [references/home-page.md](references/home-page.md) 一致。
- 检查所有真实文字图层的字体、字重、字号与行高，而不是只检查生成代码或父级样式。
- 检查页面仅有一个搜索框、一个当前一级 Tab 和一个当前底部目的地。
- 检查 Banner、双列卡、热点模块、横向信息卡与视频卡的尺寸、圆角和裁切。
- 检查长内容在首屏、上滑、返回首页、刷新、分页和空/错状态下均不被固定底部区域遮挡。
