# Space 间距

按内容关系选择间距，不从规范展示画板、标注层或外框反推生产值。

| 关系 | 间距 |
|---|---:|
| 相邻 Tag、紧密标题与辅助文字 | `4px` |
| 模块标题与内容、图片与内部文字 | `8px` |
| 紧凑双列/三列/横向卡组 | `8px` |
| 带分隔线的旧式卡片关系 | `10px` |
| 新卡片内边距 | `12px` |
| 纵向同级卡片 | `12px` |
| 横向媒体与文字 | `12px` |
| 页面左右留白、独立模块之间 | `16px` |

## 使用规则

- 标准移动端左右留白为 `16px`，主内容对齐同一内容边缘。
- 新页面纵向卡片默认 `12px`；首页双列等明确紧凑网格使用 `8px`。
- 独立模块之间使用 `16px`，模块标题与其内容使用 `8px`。
- 内容换行时保留语义间距；触控面积与视觉间距分开处理。
- 组件参考给出精确内部间距时，仅在该组件作用域覆盖本表。

## 验收

- 重复列表和卡组采用一致 gap，不用逐项 margin 拼接。
- 同一连续网格不混用 `8px` 与 `12px`。
- 安全区、键盘避让和状态栏不替代内容间距。
