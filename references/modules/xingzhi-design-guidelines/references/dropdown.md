# Dropdown 下拉菜单

## 定位与使用场景

- Dropdown 用于页面中重要的开关式筛选或单项内容选择，例如“只展示未读消息”。
- 常规场景以单选为主；可组合下拉筛选与开关式单选，或与排序、其他单选条件组成筛选栏。
- 下拉框本身不扩展搜索；当选项需要搜索、复杂多维筛选或多选操作时，应使用 Search 或 Filter View。
- 点击下拉入口后在入口下方展开选项；选择后更新入口并收起菜单。

## 入口尺寸与状态

- 菜单入口示例为 `80 × 24px`，背景 `#F5F7FA`，圆角 `20px`，左右内边距 `8px`，文字与箭头间距 `6px`。
- 入口文字使用 `12px/18px`，默认色 `#999999`；内容过长保持单行并以省略号截断。
- 收起态背景 `#F5F7FA`；展开/激活态背景 `rgba(0,210,240,0.08)`，文字使用行知主色 `#00D2F0`。
- 默认或未选择时，入口显示默认选项/占位内容；已选择后入口显示当前选项并呈现激活态。
- 多维度筛选入口可由多个 `58–80px` 子菜单项组成，间距约 `6–8px`；超出宽度时保留右侧渐变提示或折叠处理。

## 菜单面板

- 下拉列表示例宽度 `375px`，单项高度 `40px`，左右内边距 `16px`，文字字号 `12px/17px`。
- 菜单项纵向排列，背景白色；当前选中项使用 `#00D2F0` 文字、字重 `500`，未选项使用 `#222222`。
- 菜单展开区域应对齐入口左边缘或所属内容容器，避免覆盖入口本身；列表较长时在面板内滚动。
- 标签式展开可将选项排列为三列胶囊：单项 `109 × 36px`，列/行间距 `8px`，未选背景 `#F5F7FA`、圆角 `22px`，选中背景 `rgba(0,210,240,0.1)`、主色文字。
- 菜单与筛选栏组合时，菜单头部高度 `40px`，底部边界使用 `#E6EBF0` 的细分隔线。

## 交互规则

- 选择后再次展开菜单，必须高亮当前选项；入口同步显示选中内容。
- 单选下拉选择后通常即时生效；若与复杂筛选或多维操作组合，应交由 Filter View 的确定/重置流程统一提交。
- 点击入口以外区域、再次点击入口或选择完成后关闭菜单；关闭不应丢失已确认的选中值。
- 菜单选项不承担搜索功能；需要关键词定位时切换到搜索组件。

## 检查清单

- 检查入口是否为单项选择、开关式筛选或与其他筛选的合理组合。
- 检查入口 `80 × 24px`、圆角 `20px`、文字/箭头间距、收起/激活颜色和省略号规则。
- 检查菜单 `40px` 行高、选中高亮、列表对齐、长列表滚动和标签三列布局。
- 检查关闭行为、即时生效/统一提交语义，以及搜索需求是否正确转交 Search/Filter View。
