# Project 项目布局

## Purpose

- 用于项目与信息展示：顶部呈现业务标题与项目关键信息，下方直接承接信息流。
- 适合研究项目、资讯项目和理财产品项目等需要“项目识别 + 分类浏览 + 持续内容”的页面。

## Page frame

- 以 `375px` 移动画布为基准；常规内容区左右各留 `16px`，主内容宽 `343px`。
- 页面按“导航 → 顶部信息 → 关键信息 → 信息内容”纵向组织，不得让信息流抢占项目身份区。
- 顶部可使用项目主题图或品牌色背景；正文承载面使用白色，示例中以 `16px` 顶部圆角覆盖在头图之上，形成清晰层级。
- 状态栏示例高度为 `44px`；页面内 Tabs 示例高度为 `44px`。

## Top information

- 顶部信息至少包含业务标题；按项目需要补充副标题、简短描述与关键操作。
- 页面主标题使用当前标题 token，默认不超过 `20/28px 500`；描述/辅助信息使用 `12/18px 400`。图片背景上的文字需保证足够对比度。
- 订阅类项目可提供“订阅 / 已订阅 / 订阅管理”等状态，但操作必须与项目标题、描述保持同一信息域。

## Key information and navigation

- 关键信息位于项目标题与信息流之间，可承载项目数据、日期、地点、产品状态、卖点或快捷入口。
- 一级分类使用横向 Tabs：选中 `16/24px 500`、未选中 `14/22px 400`，并带 `14 × 3px` 青色圆角指示条。
- 二级分类可使用胶囊筛选项：高度 `26px`、圆角 `13px`；选中态使用品牌青色文字与浅青背景，未选态使用灰字与 `#F5F7FA` 背景。
- 分类超出可视宽度时允许横向滚动，并保留明确的筛选入口；切换分类时应保留对应列表状态。

## Information content

- 标题下直接承接信息流，可组合图文、视频、直播、研报、活动和产品卡片，但同一区域要保持统一节奏。
- 常规列表行宽 `343px`；右侧缩略图示例为 `104 × 66px`，标题与时间、作者、热度等元信息分层展示。
- 项目卡片宽 `343px`，高度随内容增长，纵向卡片间距 `12px`；可包含标题、类别/状态标签、关键数据、负责人头像与“了解详情”等操作。
- 列表标题优先使用 `14–16px` 与 `#222222`；辅助元信息使用 `12px` 与 `#999999`。
- 页面底部按业务需要放置风险揭示、免责声明和“已经到底了”等终止反馈；金融内容必须保留完整合规文案。

## Behavior

- 顶部身份区说明“这是什么项目”，Tabs/筛选说明“正在看哪一类”，信息流展示“具体内容”，三者职责不得混用。
- 订阅、报名、添加日历、查看详情等操作应反馈成功、失败和不可用状态，并在返回后保留原分类与滚动位置。
- 固定导航、筛选或底部操作不得遮挡列表、风险揭示及系统安全区。

## Review checklist

- 检查导航、顶部信息、关键信息和信息流的顺序。
- 检查 `375px` 画布、`16px` 页面边距和 `343px` 主内容宽。
- 检查标题、副标题、描述、关键操作和订阅状态是否属于同一项目身份区。
- 检查一级 Tabs、二级分类、筛选入口、溢出滚动及选中态。
- 检查各类卡片的标题、媒体、元信息与操作层级是否统一。
- 检查项目操作的状态反馈、返回状态和滚动恢复。
- 检查金融项目的风险揭示、免责声明和底部安全区是否完整且无遮挡。
