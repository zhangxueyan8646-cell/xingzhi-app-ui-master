# Input 输入框

Source: MasterGo document `行知app-规范`, nodes `XingZhi App - Design System-Input 输入框`、`Input 输入框-交互说明`、`Input 输入框-组件`（`64:40742`、`64:40972`、`64:41923`）。

## 定位与基础结构

- Input 用于用户录入信息，通常与 Form 表单组合。
- 基础结构为标题项 + 输入区 + 底部分隔线；标题与输入项可按业务采用水平或竖直排列。
- 水平表单中的普通带标题输入内容靠右对齐；无标题、带业务图标或带固定前缀的输入区按文本录入方向左对齐。
- 占位内容必须使用明确的动作提示，如“请输入”；不能用已输入内容的颜色伪装占位状态。
- 组件集只定义 `未输入 / 已输入 / 报错` 和必选 `on/off`。聚焦、禁用、只读、字符计数等未在本画板中形成独立 Input 变体，使用时应调用 `form.md` 或明确业务规则，不得自行推导视觉样式。

## 页面类与卡片类

### 页面类

- 容器宽 `375px`，基础行高 `50px`，背景 `#FFFFFF`。
- 上下内边距 `12px`，左右内边距 `16px`；有效内容宽 `343px`。
- 分隔线从左右内边距位置开始和结束，不贯穿到画布边缘。

### 卡片类

- 容器宽 `343px`，基础行高 `50px`，背景 `#FFFFFF`。
- 四周内边距 `12px`；有效内容宽 `319px`。
- 卡片类负责卡片内部字段，不额外叠加页面的 `16px` 内边距。

### 通用间距

- 默认标题与输入区间距 `16px`。
- 带下拉、带业务图标、无标题或组合操作时通常使用 `12px`。
- 已输入且带右侧操作按钮的紧凑组合可使用 `8px`；图标与相邻文本的微间距通常为 `4px`。
- 以上间距来自组件结构，不得用展示画板外框或标注间距替代。

## 文字、图标与分隔线

- 所有文字使用苹方 `PingFang SC Regular 400`；输入框内没有标题 Medium 500 的用法。
- 标题项：`14px/20px`、`#555555`。
- 必填标记：`*`，`14px/20px`、`#F24949`；紧贴标题前方。非必填时隐藏，不改变标题基线。
- 占位文字：`14px/20px`、`#BBBBBB`。
- 已输入内容：`14px/20px`，部分组件使用 `22px` 行高；颜色 `#222222`。同一表单内需保持同类输入一致。
- 报错提示：`12px/18px`、`#F24949`；错误图标 `16 × 16px`，图标与提示文字间距 `4px`。
- 业务前图标为 `20 × 20px`；清除、密码显示/隐藏等操作图标为 `16 × 16px`；选择箭头为 `12 × 12px`、`#999999`。
- 默认分隔线为 `0.5px #E6EBF0`；输入完成后的分隔线为品牌青 `#00D2F0`，表示该项填写完成。
- 报错态并不统一把分隔线改为红色：当前组件仍保留默认或完成态分隔线，错误信息通过红色文字和错误图标表达。

## 样式变体

- `默认`：标题项 + 输入区 + 分隔线。
- `带操作按钮`：标题项 + 输入区 + 单个右侧操作按钮。只允许一个便捷操作。
- `带下拉`：标题项 + 固定前置选项 + 输入区；示例为 `+86` 与 `12px` 下拉箭头，箭头与前缀间距 `4px`。
- `带下拉和操作按钮`：在前置选项与输入区之外增加一个右侧操作；必须优先保证输入区的可读宽度。
- `带 icon`：左侧 `20 × 20px` 业务图标 + 输入区，适合交易密码等需要语义标识的输入。
- `无标题`：移除标题项，输入区占据主要宽度，仍保留分隔线和状态规则。
- `无标题-带操作按钮`：无标题输入区 + 单个右侧操作按钮。
- `选择箭头`：标题项 + 右对齐选择结果/占位 + `12 × 12px` 右箭头。它用于进入选择流程，不等同于直接文本录入。

## 状态

### 未输入

- 显示占位文字 `#BBBBBB`，分隔线为 `#E6EBF0`。
- 必选状态仅通过标题前 `*` 表达，不要预先显示错误。

### 已输入

- 显示用户内容 `#222222`，分隔线切换为 `#00D2F0`。
- 可在右侧显示清除或密码显示/隐藏等唯一操作，不能同时堆叠多个快捷按钮。

### 报错

- 普通带标题变体高 `68px`。标题仍在左侧；右侧形成两层内容：上方 `18px` 错误提示行，下方已输入内容，层间距 `4px`。
- 无标题、无标题带操作按钮和带 icon 的报错组合高 `84px`：上方基础输入行 `50px`，下方错误提示行 `18px`，两者间距 `4px`，底部保留 `12px`。
- `选择箭头` 的报错态仍高 `50px`，将右侧选择内容替换为红色“重新选择”等行动提示，不增加独立错误行。
- 账号、密码、登录、注册等需要用户就地修正的场景使用内联报错；普通信息项提交失败优先用 Toast 轻量提示。
- 错误消失后恢复对应的未输入或已输入状态，不保留无效错误图标。

## 便捷操作与选择

- 右侧操作仅承载一个高频行为，如清除、显示/隐藏密码或二级选项。
- 清除操作只在已有可清除内容时出现；清除后恢复未输入状态和默认分隔线。
- 密码显示/隐藏只改变字符可见性，不移动输入内容、改变输入值或新增第二个操作。
- 带下拉的前置选项用于区号、机构等输入上下文；选择后同步更新输入规则和输入内容校验。
- 选择箭头点击整行进入选项页、下拉菜单或选择器；返回后显示选中内容，取消则保留原值。

## 验证码输入

- 验证码是专用输入形式，不使用普通标题 + 单输入区的布局。
- 规范示例为 `6` 个等距字符位，整体约 `308 × 38px`，左右内边距 `12px`，字符位间距 `20px`。
- 单个字符使用 `24px/26px`；下划线宽 `34px`，字符与下划线间距 `12px`。
- 当前字符位下划线使用 `#00D2F0`，未输入字符位使用 `#E6EBF0`；未输入位不显示伪字符。
- 输入应顺序推进并支持系统验证码自动填充；位数、重发、失败和超时逻辑由业务定义。

## 与其他规范的边界

- 字段分组、纵向/横向表单、说明文案、字符计数和提交校验遵循 `form.md`。
- 下拉入口和展开菜单分别遵循 `dropdown.md`；日期、时间或多项筛选分别调用对应 Picker 或 Filter View。
- Toast 只承载轻量、短暂、无需精确定位的错误；需要用户定位并修复当前字段时使用本规范的内联报错。
- 页面展示示例中的手机号、账号、密码和机构名称仅为演示文案，不是默认业务内容。

## 检查清单

- 检查页面类 `375 × 50px`、左右 `16px`；卡片类 `343 × 50px`、四周 `12px`。
- 检查苹方 Regular 400、标题/输入 `14px`、错误提示 `12px` 及对应行高和颜色。
- 检查默认 `#E6EBF0` 与完成 `#00D2F0` 分隔线状态，不擅自增加红色分隔线。
- 检查 `默认 / 带操作 / 带下拉 / 带下拉和操作 / 带 icon / 无标题 / 选择箭头` 是否按场景选择。
- 检查基础 `50px`、有标题报错 `68px`、无标题或带 icon 报错 `84px`、选择箭头报错 `50px`。
- 检查必选 on/off、内容对齐、操作数量及 `20/16/12px` 图标层级。
- 检查普通错误使用 Toast，账号密码等需精确修正的场景使用内联报错。
- 检查验证码的六位结构、字符字号、下划线宽度和当前位状态。
